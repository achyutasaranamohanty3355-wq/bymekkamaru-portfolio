Role: UI/UX DesignerPlatform: Android mobile appMarket: Farmers in IndiaTools: Figma · FigJam
← Back to projects
01 / Overview

About the project

AgriSathi is a smart farming companion concept. Its interface begins by helping users choose a language and set up a farmer profile before reaching the main dashboard.

02 / Problem space

The challenge

The project explores how a mobile experience can make farming-related information more approachable through clear onboarding, localized language choices and a focused home screen.

03 / Design approach

From problem to experience

The selected screens show the welcome and language-selection experience, farmer profile setup and the home dashboard. The case study will focus on the actual interface decisions visible in these designs rather than adding unverified product capabilities.
